# WorldWideWeb

A WorldWideWeb browser in JavaScript - JSS + mashlib in Electron.

## Quick Start

```bash
npx worldwideweb
```

## Install Globally

```bash
npm install -g worldwideweb
worldwideweb
```

## Development

```bash
git clone https://github.com/melvincarvalho/worldwideweb.git
cd worldwideweb
npm install
npm start
```

## Configure

Edit `config.json`:

```json
{
  "port": 3012,
  "width": 1200,
  "height": 800,
  "root": "./data"
}
```
